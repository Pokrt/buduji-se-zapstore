# Buduji se – Zapstore

Release metadata for the Android app **Buduji se** (`se.buduji.app`), a Czech self-development diary:
a day in three thirds, inspired by Tomáš Baťa, grounded in behavioural science.

This repository only holds `zapstore.yaml`, which [Zapstore](https://zapstore.dev) uses to verify the
publisher. The app's source code is not public.

Testing builds only.
